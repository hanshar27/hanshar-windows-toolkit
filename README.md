# Hanshar Windows Toolkit

Hanshar Windows Toolkit is a polished Windows 10/11 utility desktop application built with Python and CustomTkinter. It combines a modular dashboard, storage safety controls, power utilities, network diagnostics, system monitoring, maintenance tools, and packaging support into a single desktop experience.

## Highlights

- Warm charcoal desktop shell with flat icon navigation
- Bento-grid dashboard with live CPU/RAM circular gauges, system metrics, network rates, and performance history
- GPU temperature support through NVIDIA `nvidia-smi` or LibreHardwareMonitor/OpenHardwareMonitor; the temperature card never substitutes CPU load for temperature
- Safe storage cleaner with protected location filtering
- Storage Cleaner scans user `%TEMP%`, Windows Temp, and Prefetch; Recycle Bin cleanup is opt-in and requires confirmation
- Shutdown timer and power manager actions
- Network diagnostics such as ping, DNS lookup, and adapter checks
- Security-aware maintenance and startup configuration
- Confirmed standby-memory cache purge with administrator elevation
- Activity logging and system report export
- Complete MSInfo32 and DxDiag reports in the System Information page
- Single glass-style interface with an adjustable Windows acrylic backdrop
- Windows EXE and installer-ready packaging workflow

## Project setup

Requirements: Windows 10/11 and Python 3.10 or newer.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Alternatively, run `run_app.ps1` from PowerShell after installing the dependencies.

## Run tests

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Build Windows EXE

```powershell
.\.venv\Scripts\python.exe build_exe.py
```

The build output is generated in the `dist` directory as `HansharWindowsToolkit.exe`.

## Build Windows installer

```powershell
.\.venv\Scripts\python.exe build_installer.py
```

This script checks for Inno Setup (`iscc.exe`) and writes `HansharWindowsToolkit-Setup.exe` into `installer/` when available. The installer is included at [`installer/HansharWindowsToolkit-Setup.exe`](./installer/HansharWindowsToolkit-Setup.exe) for direct download from the repository.
The installer build requires Inno Setup 6 or 7. Other generated EXEs, temporary build files, local reports, and logs are excluded from source control.

## Safety notes

- Destructive operations require explicit user confirmation.
- Protected Windows and user directories are excluded from cleanup scans.
- Active PyInstaller `_MEI` runtime folders are excluded from Temp cleanup to keep the running application intact.
- Emptying the Recycle Bin is a separate opt-in action and permanently removes its contents from all drives; Windows may recreate temporary and Prefetch cache files.
- Windows-specific actions such as startup registration and shutdown scheduling are gated behind safe validation logic.
- System Information reports are generated locally and saved under `reports/`; they can contain device and software details, so review them before sharing.
- Clearing the Windows standby memory cache requires explicit confirmation and administrator approval. Windows can refill the cache; this does not increase physical memory.

## Glass appearance

Open **Settings** and adjust **Blur strength**. The glass backdrop applies immediately and is saved for the next launch. Windows controls the blur radius; the slider changes the acrylic tint/transparency strength. The effect requires Windows desktop composition/transparency effects to be enabled. Older theme preferences are ignored.

## Clear standby memory cache

Open **Maintenance** and select **Clear Memory Cache**. After confirmation, approve the Windows UAC prompt if shown. The utility purges Windows standby pages; this releases cached RAM for current use but does not increase installed RAM, and Windows may cache those pages again. Cancelling UAC or an unsupported Windows response is reported in the app or the elevated confirmation dialog.

## System Information reports

Open **System Information** from the sidebar, then select **Generate Full Reports** to collect the complete MSInfo32 and DxDiag text reports. Generation runs in the background and may take a few minutes. In a packaged app, the reports are saved under `%LOCALAPPDATA%\RayhanWindowsToolkit\reports`; in a source run, they are saved under the project `reports/` folder. Use **Load Saved Reports** to display reports from an earlier run. Reports generated by older packaged builds may have been stored in a temporary folder, so generate them once again after updating the app.

## Release status

The project is structured for final Windows packaging and can be built as a desktop release bundle when run on a compatible Windows machine.
